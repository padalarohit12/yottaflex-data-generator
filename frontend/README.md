# YottaFlex Data Explorer Frontend

A simple web-based data explorer for visualizing the YottaFlex synthetic dataset.

## Features
- Overview dashboard with dataset statistics
- Ground truth / anomalies viewer showing all labeled edge cases
- Sellers browser
- Orders browser (sample view)

## Usage
Open `index.html` in a web browser. The explorer loads data from `../data/generated/starter/json/` and `../ground_truth/ground_truth.json`.

## Note
This is a static frontend for exploring the generated synthetic data.
